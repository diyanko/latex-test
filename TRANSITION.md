# Officer Transition Checklist

Use this checklist at every officer turnover.

## Access

- [ ] Remove departing officers from write/admin teams.
- [ ] Add incoming officers to correct team(s).
- [ ] Confirm at least two org admins remain.
- [ ] Check for lingering personal collaborators with write access.

## Reliability

- [ ] Run compile workflow and confirm success.
- [ ] Confirm manual release workflow is functional.
- [ ] Confirm at least two independent backups exist.

## Governance Integrity

- [ ] Confirm release policy: every release must include an approval record link.
- [ ] Confirm latest release assets include PDF.
- [ ] Confirm annual archive export plan is known by current officers.
